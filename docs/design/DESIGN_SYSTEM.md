# Streak It — Design System

## Philosophy
> "Color gets its power from scarcity."

One color — #FF4D1C — deployed only on streak numbers, active states, and CTAs. Everything else: black, white, gray.

## Color Palette

| Color | Hex | Role |
|---|---|---|
| Black | #000000 | Scaffold background |
| Near Black | #0A0A0A | Bottom nav, dialogs |
| Deep Charcoal | #141414 | Cards, filled inputs |
| Charcoal | #1A1A1A | Card backgrounds |
| Dark Gray | #2A2A2A | Borders, dividers |
| Mid Gray | #4A4A4A | Secondary text |
| Muted Gray | #6B6B6B | Labels, captions |
| Light Gray | #9B9B9B | Placeholder hints |
| Off White | #D6D6D6 | Body text |
| Near White | #F2F2F2 | Headlines |
| White | #FFFFFF | High emphasis |
| **Accent** | **#FF4D1C** | **Streaks. CTAs. Active. ONLY.** |
| Success | #16A34A | Completion |
| Warning | #CA8A04 | Attention |
| Error | #DC2626 | Destructive |

## Typography
**Font**: Space Grotesk — geometric sans-serif, bold weight reads brutalist.

## Rules
1. **No shadows.** Ever.
2. **No gradients.** Flat color only.
3. **No rounded corners.** BorderRadius.circular(0).
4. **Borders > shadows.** For separation and hierarchy.
5. **#FF4D1C is earned.** Only on streaks, CTAs, active states.
6. **Negative space is intentional.** Don't fill it.
